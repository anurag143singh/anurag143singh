## 🚀 Featured work

<details open>
<summary><b>🛡️ Anurag PC Sentinel VX — PC health & security dashboard</b></summary>
<br>

A Windows desktop application for real-time PC health, security monitoring, and optimisation. It brings system performance, health, network activity, battery condition, temperature information, and basic system events into one clear dashboard.

**Highlights**

- CPU, RAM, disk, network, battery, temperature, and system-status monitoring
- Lite, Balanced, and Performance modes for different PC types
- Optional voice or text commands with safe microphone handling
- Installer and portable release options
- Local-first profile saving with no email, mobile number, or OTP required

<details>
<summary><b>🔥 LPG Security System — ESP32 emergency-response prototype</b></summary>
<br>

An ESP32-based LPG and fire-safety prototype that monitors gas, flame, temperature, and humidity conditions. The core emergency decision stays local to the device while Blynk provides telemetry and notifications.

**Highlights**

- MQ-6 gas sensing, flame detection, and DHT11 temperature/humidity monitoring
- Local emergency response for gas, flame, or high-temperature conditions
- OLED status display, alarm LEDs, buzzer, relay, servo, and fan control
- Blynk telemetry, event notifications, and a controlled testing mode
- Safety documentation, circuit diagrams, setup notes, and testing guidance

</details>
