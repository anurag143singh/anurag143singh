**Real-time Windows PC health, security monitoring, and optimisation**

### 🔥 LPG Security System

**ESP32 gas and fire safety prototype with local emergency control**

[![Explore LPG project](https://img.shields.io/badge/EXPLORE-LPG%20SECURITY-FF4B6E?style=for-the-badge&labelColor=0B1020)](https://github.com/anurag143singh/LPG-Security-System)

**Safety deck**

- MQ-6 gas sensing, flame detection, and DHT11 environmental monitoring
- Local emergency response for gas, flame, and high-temperature conditions
- OLED, alarm LEDs, buzzer, relay, servo, and fan control
- Blynk telemetry, event notifications, and controlled testing mode
- Circuit diagrams, setup notes, and safety documentation

</td>
